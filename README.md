# Консольная игра «Крестики-нолики» (Tic-Tac-Toe)

Классическая игра «Крестики-нолики» для двух игроков, реализованная в консоли. Проект написан на Python с использованием принципов объектно-ориентированного программирования (ООП) и строгим соблюдением Git-flow (разработка каждой функции в отдельной ветке).

## Особенности проекта
- **Архитектура ООП:** Четкое разделение ответственности между классами `Board` (логика доски) и `Game` (игровой процесс).
- **Надежная валидация:** Защита от некорректного ввода (буквы вместо чисел, выход за пределы поля от 1 до 3, попытки хода в занятую клетку).
- **Точная проверка состояний:** Алгоритм автоматически распознает победные комбинации (строки, столбцы, диагонали) и объявляет ничью, если свободных клеток не осталось.
- **Режим рестарта:** После окончания партии можно запустить новую игру без перезапуска скрипта.

## Структура проекта
* `board.py` — класс `Board`. Хранит матрицу поля, отвечает за отрисовку, применение ходов и проверку статуса игры (победа/ничья).
* `game.py` — класс `Game`. Управляет игровым циклом, сменой игроков и запросом координат.
* `main.py` — точка входа в приложение. Инициализирует объекты и содержит внешний цикл перезапуска.

## Требования
* Python 3.x (в проекте использовался Python 3.15)
